# Local Mixamo imports

The public gallery includes a rendered **Samba dancing** G1 preview from the
Three.js Mixamo sample. Source FBX and converted NPZ files are not published.

See the [importer and reproduction instructions](../../data_generator/mixamo/README.md).
Locally, `samba_dancing/motion.npz` and its paired video can be inspected using
`uv run python tools/build_catalog.py --include-local`, then `docs/local.html`.
