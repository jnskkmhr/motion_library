# Local LAFAN previews

Five local G1 examples can be built using the [LAFAN importer](../../data_generator/lafan/README.md).
The converted NPZ/video directories are ignored by Git under the source's
CC BY-NC-ND terms. Run `uv run python tools/build_catalog.py --include-local`,
then open `docs/local.html` to browse available local clips.
